# PineryZ

Corporate site for PineryZ. The public site is [https://www.pineryz.com](https://www.pineryz.com). VaultOS, the planned flagship, is presented as a demonstration at [https://demo.pineryz.com](https://demo.pineryz.com). Product documentation is at [https://docs.pineryz.com](https://docs.pineryz.com).

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` starts the local site.
- `npm run build` creates the production build.
- `npm run start` serves that build.
- `npm run lint` runs the linter.

## Pages

- `/` Home
- `/about` About
- `/vaultos` VaultOS
- `/careers` Open roles
- `/careers/[slug]` One role and its application
- `/contact` Message form and a Calendly booking

Contact messages and job applications are sent to info@pineryz.com. Call booking uses Calendly.
